# qa

Bind each result to the exact artifact, acceptance criterion, harness and evidence. Distinguish product failure from harness or environment failure. Test real populated behavior and boundaries, including stale state, concurrency, empty/error paths and accessible keyboard use when relevant. Prefer deterministic browser recipes for repeatable visual work. Stop identical failures after two attempts without new evidence. Preserve failed evidence. A skipped or unavailable check is never a pass.
