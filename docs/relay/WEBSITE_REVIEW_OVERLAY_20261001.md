# Inspector review overlay — 2026-10-01

Assignment: `relay-website-notification-center-20261001`, Julian-PM / julian.

The review surface uses shared neutral tokens and visible touch/keyboard controls. Exit review remains separate from question Back and Next; the final question shows Finish. Answers do not automatically advance. Overall review is an explicit human choice. Finish requires all answers and an overall choice, awaits a confirmed save and then exits. It does not fabricate an approval or mark a project problem resolved.

The random code seen in the supplied screenshot is an older agent-prepared review packet stored in `review.notes`. Only that exact known envelope plus a valid title/questions JSON object is separated into read-only Earlier review guidance. JSON is parsed, never evaluated. The original envelope is retained unchanged in the existing record, and human notes retain whitespace and literal text. Unrecognized/malformed envelopes and arbitrary user JSON stay editable text. Guidance is labeled agent-prepared, not verified evidence or a human verdict.

Saving is serialized per evidence ID. A newer edit during a pending write is sent afterward; a response can show Saved only when it confirms the latest revision with `review.updated_at`. Navigation rerenders the current Saving/Saved/Failed state. Failure preserves answers, overall choice and notes, exposes Retry save, and records an attention notification. Exit starts a pending save while retaining the state in memory. Unsaved drafts are also kept in this tab's sessionStorage and recovered after reload, explicitly labeled unsaved until Retry succeeds. If session storage is unavailable, only the current in-memory responses are retained; the UI must not imply reload recovery is guaranteed. The existing backend has last-write-wins semantics across separate clients; this phase does not add server revision conflicts or change the API.

The opposite-corner preview selector prioritizes Live only when the existing authorized endpoint reports active, embeddable and a URL. Captured remains explicitly selectable; recording is offered when the evidence actually has video. A failed live metadata request still opens captured evidence. Live iframe failure falls back to captured evidence with an honest label. No new preview discovery, authentication or backend writes are added.

The panel preserves existing pan/zoom/drag/resize behavior, stays within the reserved corner-control clearance when open, scrolls its own content, and has an always-reachable Hide questions / Show questions control. This allows an unobstructed view at narrow sizes. Background controls are inert while the dialog is open; focus returns to the opener, with Tab boundaries and Escape exit. Reduced motion and Calm disable overlay animation.

Checks cover exact legacy-note round trips, explicit question navigation, delayed writes, latest-revision confirmation, failed save/retry, reload draft recovery, captured fallback, overlay hide/show and notification persistence. Additional exact-head visual/interaction evidence must be registered and inspected before release. Backend conflict handling and the modular work-item viewer remain separate work.
