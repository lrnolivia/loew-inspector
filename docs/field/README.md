# field documentation ownership

Canonical non-product documentation for `lrnolivia/field`.

- `product/` mirrors source-authoritative field product docs. The repository copies remain authoritative.
- `handoffs/` preserves implementation handoffs, audits, continuation records, and QA-derived execution history.
- `qa/` is the canonical field-specific QA overlay under Runner section 11 and section 18.

The repository may retain tooling-required copies inside `.field/handoff-kit/`; those copies are not the canonical home for execution law or project state.
